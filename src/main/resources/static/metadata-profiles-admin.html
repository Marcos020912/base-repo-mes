Perfiles de metadatos

Valores iniciales y requisitos adicionales aprobados para nuevos depósitos.

Los perfiles nunca eliminan requisitos base ni completan DOI, autoría, privacidad o declaraciones metodológicas. Al aplicar un perfil se guarda una copia de sus reglas en el dataset. Su posterior modificación o desactivación no cambia esa copia.
